🎬 Watchly

Watchly is a modern movie discovery web application that allows users to explore movies, TV series, and actors, view trailers, read reviews, and find where to watch their favorite content.

---

🚀 Features

- 🔍 Search System
  
  - Search for movies, TV shows, and actors
  - Smart search suggestions (real-time)

- 🎥 Movie & TV Details
  
  - Full details (title, year, rating, overview)
  - Trailer (YouTube integration)
  - Cast and actors
  - Reviews

- 👤 Actor Pages
  
  - Actor biography
  - Known for (movies & series)

- ❤️ Favorites & Watchlist
  
  - Save movies and series
  - Access anytime using local storage

- 📺 Where to Watch
  
  - Discover available streaming platforms (Netflix, Prime Video…)
  - Direct "Watch Now" links

- 🔥 Homepage Sections
  
  - Trending
  - Popular
  - Coming Soon

- 🧠 Advanced Filters
  
  - Filter by:
    - Year
    - Rating
    - Genre (multi-select)
    - Media type (movie / TV)

- 📄 Pagination
  
  - Navigate between pages of results

- 🕘 Recently Viewed
  
  - Automatically tracks viewed content

---

🛠️ Tech Stack

- HTML5
- CSS3 (Responsive Design + Flex/Grid)
- JavaScript (Vanilla JS)
- Bootstrap Icons
- TMDB API (The Movie Database)

---

📡 API

This project uses the TMDB API to fetch:

- Movies & TV data
- Actors information
- Trailers
- Reviews
- Watch providers

👉 https://www.themoviedb.org/

---

🎯 Project Purpose

Watchly is not a streaming platform.
It is a movie discovery platform that helps users:

«Discover what to watch and where to watch it.»

---

📱 Responsive Design

The application is fully responsive and works on:

- 📱 Mobile
- 💻 Desktop
- 📊 Tablet

---

⚠️ Notes

- This project does not stream movies directly
- It provides information + official viewing sources
- Data is powered by TMDB and JustWatch
